# ForestGuard AI · 森林防灭火闭环演示与算法说明

## 1. 「侦察—决策—扑救—扑灭」完整闭环

1. **随机起火与预警**：登录 10 秒后，系统开始随机生成火点坐标、初始强度与过火面积，并推送告警记录。
2. **自主协同调度**：系统按火点自动计算并下发调度方案，在无需人工确认的情况下选出最优无人机（空中侦察 / 压制火头）与地面机器人（火线正面强攻 / 隔离带阻断 / 洒水降温）。
3. **赶赴与扑救动画**：地图上显示各装备赶赴火点的虚线轨迹；到达火线后自动开启喷水/阻燃剂压制，呈现蓝色喷洒粒子流。
4. **扑灭判定与返航**：火势强度在风速/湿度蔓延与编队压制的动态对抗下逐步降至 `0%`，状态切换为 **「已扑灭 ✓」**，推送灭火捷报（耗时、峰值过火面积、总耗水量），编队自动返回所属基地待命；水量耗尽时返航补给并自动补充可用装备。
5. **装备过温休整与接替**：演示中机身温度超过 60 ℃ 或电量低于 30% 时停止作业并返所属基地；系统优先让同类型可用装备接替原火点任务，暂无可用装备时持续重试。返回后温度降至 35 ℃ 及以下且补给完成才可重新调度。阈值仅为仿真参数，不代表真实设备安全标准。
6. **倍速推演**：支持 `1× / 2× / 4×` 仿真倍速切换，便于快速演示完整灭火过程。

## 2. 自主调度评判标准

系统对可用装备（电量 $\ge 30\%$）按以下公式评分；「多机器人协作」页的派遣日志展示各次评分依据：

$$\text{综合得分} = 0.40 \times \text{能力匹配} + 0.25 \times \text{距离得分} + 0.20 \times \text{剩余电量} + 0.15 \times \text{载荷/水量}$$

- **能力匹配（40%）**：空中侦察/中继任务优先匹配 `UAV`，地面强攻/隔离带/洒水任务优先匹配 `UGV`。
- **距离得分（25%）**：距当前火点越近得分越高。
- **剩余电量（20%）**：确保装备具备足够续航完成往返与作业。
- **载荷/水量（15%）**：优先指派灭火剂/水量充足的单元。

## 3. 3D 第一人称设备控制

在「装备管理」页打开任意装备的 **「遥控终端」**，即可进入 `FirstPerson3DView` 3D 第一人称视角：
- **视角与移动**：支持键盘 `W/S` 前进后退、`A/D` 或 `J/L` 左右转动视角、`I/K` 俯仰，以及鼠标左键拖拽自由环视。
- **灭火与热成像**：第一人称喷水效果与仿真实际喷水状态同步，支持红外热成像通道切换。

## 路径规划（演示）

在自主导航页按设备选择风险加权 A*、A* 或 Dijkstra，并调整该设备的风向、风速、坡度参数。风险加权 A* 是人工设定代价的演示，不是训练过的强化学习模型；原 RRT* 选项未实现，已移除。巡逻、侦察、扑救、返航均执行同一设备路线；地图展示的是当前位置开始的剩余折线。地面设备静态栅格终点不可达时停止并提示，无人机演示为飞越地面障碍，不模拟禁飞区；随机起火避开障碍栅格。手动指定到障碍内的火点可能无法抵达，不能保证扑灭。此规划未验证真实环境，不用于实战。

巡逻轮岗依次由北山与东坡基地、西林与南谷基地各派一架；两架均完成后才切换下一组，基地无可用无人机时等待。无人机完成巡逻后返基地；离线时由同基地设备继承进度。巡逻无人机按多条往返航带扫描，使用仿真视幅（地图归一化半径 0.11）记录实际轨迹覆盖的栅格，绕行后对未覆盖栅格自动补扫；全部栅格完成前不参与火情调度。安全返航可中断巡逻，休整后在巡逻名额可用时继续原进度。无人机规划演示为飞越地面障碍，未建模禁飞区及真实传感器，速度和覆盖率均不代表实测值。

## 协作日志

多机器人协作页按火点列出实时装备与任务阶段，并记录发现、侦察、派遣、到场、退出、接替、等待补派和扑灭。日志保留本次演练最近 200 条，重置演练后清空；内容是仿真事件，不表示真实装备通信或路径冲突协商。
