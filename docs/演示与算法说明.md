# ForestGuard AI · 森林防灭火闭环演示与算法说明

## 1. 「侦察—决策—扑救—扑灭」完整闭环

1. **随机起火与预警**：在「指挥总览」点击 **「随机起火」**，系统随机生成火点坐标、初始强度（62%–88%）与过火面积，并立即推送一级火灾预警弹窗与告警记录。
2. **自主协同调度**：系统自动调用 `SimEngine.evaluate_and_dispatch()`，在无需人工干预的情况下选出最优无人机（空中侦察 / 压制火头）与地面机器人（火线正面强攻 / 隔离带阻断 / 洒水降温）。
3. **赶赴与扑救动画**：地图上显示各装备赶赴火点的虚线轨迹；到达火线后自动开启喷水/阻燃剂压制，呈现蓝色喷洒粒子流。
4. **扑灭判定与返航**：火势强度在风速/湿度蔓延与编队压制的动态对抗下逐步降至 `0%`，状态切换为 **「已扑灭 ✓」**，推送灭火捷报（耗时、峰值过火面积、总耗水量），编队自动返航待命。
5. **倍速推演**：支持 `1× / 2× / 4×` 仿真倍速切换，便于快速演示完整灭火过程。

## 2. 自主调度评判标准

在「多机器人协作」页的 **「自主协同调度 · 任务安排说明与评判标准」** 面板中，系统按以下加权公式对在线装备（电量 $\ge 18\%$）评分：

$$\text{综合得分} = 0.40 \times \text{能力匹配} + 0.25 \times \text{距离得分} + 0.20 \times \text{剩余电量} + 0.15 \times \text{载荷/水量}$$

- **能力匹配（40%）**：空中侦察/中继任务优先匹配 `UAV`，地面强攻/隔离带/洒水任务优先匹配 `UGV`。
- **距离得分（25%）**：距当前火点越近得分越高。
- **剩余电量（20%）**：确保装备具备足够续航完成往返与作业。
- **载荷/水量（15%）**：优先指派灭火剂/水量充足的单元。

## 3. 3D 第一人称设备控制

在「装备管理」页打开任意装备的 **「遥控终端」**，即可进入 `FirstPerson3DView` 3D 第一人称视角：
- **视角与移动**：支持键盘 `W/S` 前进后退、`A/D` 或 `J/L` 左右转动视角、`I/K` 俯仰，以及鼠标左键拖拽自由环视。
- **灭火与热成像**：支持开启/关闭喷洒载荷（第一人称喷水灭火水柱特效）与红外热成像通道切换。
